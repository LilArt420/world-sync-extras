# World Sync Extras

Optional extras for the World Sync server content (the official maps,
monsters, spawns, warps and service NPCs from the iRO/kRO clients):

- **Entrances** (setting `entrances`, off by default): 34 portals from
  rAthena's towns and fields into the maps World Sync fills (Biosphere,
  Jormungandr, Chapter 2...). The server leaves them out on purpose: a
  player whose client lacks those maps would hang on the loading screen.
  Turn it on only with recent iRO/kRO client data.
- **Placeholder NPCs** (setting `placeholders`): 740 official NPCs whose
  dialog and logic exist in no server data yet - mostly Episode 20/21 and
  Chapter 1/2 maps, plus markers from the client's signboard list (iRO's
  S3 Season NPCs, event exchanges). They stand where the client puts them,
  with their own sprite and name, and greet you.
- **@npcplace** (setting `npc_mover`, GM level 60+): stand next to any NPC
  and type `@npcplace` to move it where you stand, nudge it a cell, or put
  it back. Moves are kept across restarts. `@npcplace list` shows them.

Requires the World Sync content on the server (maps such as `jor_mbase`,
`star_frst`, `ch1_geffen` must be loaded), renewal era.

Generated by `tools/world_sync/generate.py --placeholders` in
https://github.com/LilArt420/rathena (branch `world-sync`).
